# drago_inappwebview

Inline webview, headless webview and in-app browser for Flutter (Android, iOS, macOS, Windows, Linux, Web).

A single-package fork of [pichillilorenzo/flutter_inappwebview](https://github.com/pichillilorenzo/flutter_inappwebview) (Apache-2.0). The package lives in [`drago_inappwebview/`](drago_inappwebview) - see its [README](drago_inappwebview/README.md) for installation and the differences from upstream.

```yaml
dependencies:
  drago_inappwebview:
    git:
      url: https://github.com/selvam920/drago_inappwebview
      path: drago_inappwebview
```

API docs (upstream): [inappwebview.dev/docs](https://inappwebview.dev/docs/intro)
